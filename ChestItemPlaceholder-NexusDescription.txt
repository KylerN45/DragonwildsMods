[center][color=#D4D4D8][color=#e4e4e7]Chest Item Placeholder keeps a configured number of items in a player-built chest when you transfer a stack. This helps you remember which item types belong in each chest.[/color][/color][/center]



[center][color=#D4D4D8]CHEST ORGANIZATION · LESS INVENTORY WORK[/color][/center]
[line]
[color=#D4D4D8]W H A T   I S   T H E   M O D[/color]


Chest Item Placeholder monitors transfers from player-built chests. If one transfer would take a stack from more than one item to zero, the mod returns the configured reserve to the chest. The default reserve is one item.

You can still take the final item later. If a transfer starts with exactly one item in the chest, the mod permits that transfer.

[line]
[color=#D4D4D8]C O N F I G U R A T I O N[/color]


Close the game before you change the configuration.

Open Scripts\config.lua. Set PLACEHOLDER_AMOUNT to the number of items that the mod must return after a protected transfer. The default value is 1.

The final single item is always removable.


[line]
[color=#D4D4D8]H O W   I T   W O R K S[/color]


The mod compares the chest item loss with the local player inventory gain. It returns the reserve when the same item moves to the local player. It uses the game server inventory transfer function to return the item to its original chest slot.

The transferred item can appear briefly in the player inventory before the reserve returns to the chest.

The mod provides the public ChestItemPlaceholder.active value. It also provides ChestItemPlaceholder.placeholderAmount and ChestItemPlaceholder.version. Other mods can read these values.

[color=#D4D4D8]F A Q[/color]


[list]
[*][color=#D4D4D8][b]Does it support controllers?[/b] - Yes. The chest option supports controller focus. The A button and right trigger transfer methods are supported.[/color][/*]
[*][color=#D4D4D8][b]Can I take the final item?[/b] - Yes. Transfer the reserved single item as a separate action.[/color][/*]
[*][color=#D4D4D8][b]Why does an item briefly appear in my inventory?[/b] - The mod verifies the completed local transfer before it returns the reserve through the game server.[/color][/*]
[*][color=#D4D4D8][b]Does it support multiplayer?[/b] - The mod filters for transfers to the local player. Multiplayer behavior needs more testing.[/color][/*]
[*][color=#D4D4D8][b]Does it support Game Pass?[/b] - Game Pass has not been tested.[/color][/*]
[/list]
